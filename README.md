Entry for the [make.fun bounty "One Star, Five Stars for the Food"](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

## What it does

`main.py` (Python 3, standard library only) writes a single sentence — at most
200 characters — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when
set): a one-star review of planet Earth written in the voice of an alien
tourist, still slipping in a real compliment about the food.

## The review

> Earth sunburned all six of my tentacles, towed my saucer, and made me queue two hours for a table, yet the biryani was so good I'd fly 40 light-years back for seconds — one star.

## Run it

```sh
python3 main.py
```
